COE4DK4 Lab 1 - Performance of Single Server Queueing Systems
Group Setup

This repository contains the code, experiment results, plots, and report material for COE4DK4 Lab 1: Performance of Single Server Queueing Systems.

The lab investigates the behaviour of:  

• M/D/1 queueing systems  
• M/M/1 queueing systems  
• Finite-capacity single-server queues  

The main performance measures are:  

• Mean customer delay  
• Mean number of customers in the system  
• Server utilization  
• Customer rejection probability for finite queues  
• Sensitivity to random seed and simulation run length  

The lab handout requires one group submission, with a maximum group size of three students.
